# 🔢 Verificador de Zero em C

Um programa simples feito em linguagem C que recebe um número inteiro digitado pelo usuário e valida se esse número é igual a zero ou não.

## 🚀 Tecnologias Utilizadas

*   **Linguagem:** C

## 💻 Como Compilar e Executar

Para rodar este projeto no seu computador, você precisa de um compilador de C (como o GCC) instalado.

### Passo 1: Clonar o repositório
```bash
git clone https://github.com/trindvini/VerificadorZero.git
cd nome-do-seu-repositorio
```

### Passo 2: Compilar o código
Digite o comando abaixo no seu terminal para gerar o arquivo executável:
```bash
gcc main.c -o verificador -Wall
```

### Passo 3: Executar o programa
Agora basta iniciar o programa gerado:
```bash
# No Windows
verificador.exe

# No Linux ou Mac
./verificador
```
